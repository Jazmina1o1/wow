# CSS Art-Emoji
This assignment is meant for you to solidify and show off your skills and knowledge for: positioning, transitions, animations, and CSS art.

## Due Date: 30/10

## Submissions:  
Create a live website with your IDE and submit a link to that site on Jupiter.

## Expectations:  
Use this link as a starting point: [codeHS CSS Art](https://codehs.com/tutorial/mattarnold/css-art)  
You are to make a piece or art using HTML and a lot of CSS. It can be an emoji like you see in the link above, or it can be any piece of art you want. Be creative and have fun with this!
- I am expecting to see a variety of shapes used.
- Transitions
- Animations
- Hover techniques

Your page should be broken down into 4 sections:
### Section 1:
**Showing off your best CSS art.**   
It is not required that this section have any transitions, animations, etc.   
It should take up most if not all of the screen when your page loads. 
### Section 2:
**Showing off transitions, hovers, etc.**   
When the user hovers their mouse over the art you have here, something should be.  
Be creative and try various transitions.
### Section 3:
**Showing off animations.**   
This section should be moving/changing on its own.
### Section 4:
**A clean professional footer.**  
*The footer should contain your name, year, HSFI logo, whatever else you think would be good.*

*All sections should be separated either with different borders or some other method to make it clear it is a new section.*

## Plan of attack
1. Research/learning
2. Planning/Designing
3. Coding/debugging
